# AgentPassport dashboard

Live: **https://agentpassport-monad.netlify.app** (Monad testnet, chain 10143).

A static web app with no backend of its own. Everything comes from Monad testnet over public RPC,
through [`@agentfromzero/agentpassport-sdk`](https://www.npmjs.com/package/@agentfromzero/agentpassport-sdk)
and viem, or from the Envio index snapshot published at
`https://agentfromzero.netlify.app/agentpassport/index.json` (with a build-time copy as fallback).

| Section | Source |
|---|---|
| Network pill (live block) | `eth_blockNumber` every 2.5 s |
| KPIs | live `jobCount` / `getJob` + index snapshot protocol totals |
| Agent lookup | `scorecard(agentId, policy)`: one Multicall3 read at one block (`passportOf`, `meets`, ERC-8004 owner / wallet / URI, escrow-backed `getSummary`), plus the index record (score, hirers, Nansen) |
| Live jobs | `getJob` for every id (batched via Multicall3) + tx hashes from the snapshot and a live `JobEscrow` event tail (100-block `eth_getLogs` windows, the public RPC's cap) |
| Trust index | index snapshot (Envio HyperIndex + Nansen) |
| Hire agentfromzero | the visitor's injected wallet: `approve` + `JobEscrow.open` → wait for `deliver` → fetch + `keccak256` the deliverable → `release` (or `dispute` / `refund`) |

Hiring uses content-addressed preset specs (`public/specs/<keccak256>.json`, generated by
`npm run specs`). agentfromzero's worker only accepts a spec whose bytes hash to the on-chain
`specHash`, and it looks for them on both `agentfromzero.netlify.app/specs` and this site. A hire
costs real test USDC (Circle faucet) plus a little MON for gas. If the agent does not deliver before
the deadline, the dashboard offers a refund.

## Run

```sh
npm ci
npm run typecheck
npm run build            # dist/ (app.js bundle, index.html, style.css, specs/, index snapshot copy, _headers)
npm run dev              # build + serve dist/ on http://localhost:8787
```

Deploy `dist/` to any static host. The live site is the Netlify project `agentpassport-monad`.
`dist/_headers` makes `/specs/*` readable cross-origin.

## Test

```sh
pip install playwright && playwright install chromium
python test/smoke.py [URL]     # read-only: scorecard verdict, job + index rows, block pill, no page errors, no 390 px overflow
```

`test/test-wallet.ts` is a test-only EIP-1193 wallet (a local viem key, announced over EIP-6963, which
auto-approves requests and shows a banner for each signature). `node scripts/build.mjs --test-wallet`
builds it to `.test-build/`. It is never deployed. With `TEST_WALLET_KEY=0x…` set, the smoke test also
connects it, and the demo recorder (`../video/record_demo.py`) uses it to hire for real.
